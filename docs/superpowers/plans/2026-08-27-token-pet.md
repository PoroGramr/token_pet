# TokenPet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code 5시간 한도의 남은 비율을 애니메이션 캐릭터에 표시하는 macOS 상주 앱을 만든다.

**Architecture:** 테스트 가능한 순수 로직을 `TokenPetCore`에 두고 AppKit 실행 타깃이 Keychain, URLSession, NSPanel, SMAppService를 연결한다. 빌드 스크립트가 원본 프레임을 정규화하고 앱 번들을 조립한다.

**Tech Stack:** Swift 6.2, Swift Package Manager, AppKit, Security, ServiceManagement

**Spec:** `docs/superpowers/specs/2026-08-27-token-pet-design.md`

## Global Constraints

- macOS 14 이상, arm64.
- 캐릭터 120x120pt, 3fps ping-pong 애니메이션.
- 사용량은 5분 주기, 오류 시 마지막 정상 값 유지.
- 인증 비밀은 파일이나 로그에 기록하지 않는다.
