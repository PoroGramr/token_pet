# TokenPet Design

## Goal

macOS 화면 우측 하단에 애니메이션 캐릭터를 항상 표시하고, 캐릭터의 배 중앙에 Claude Code 5시간 한도의 남은 비율을 표시한다.

## Experience

- `img/1.png`부터 `img/4.png`까지를 `1-2-3-4-3-2` 순서, 3fps로 계속 재생한다.
- 위젯은 120x120pt이며 최초 위치는 주 화면 우측 하단 20pt 여백이다.
- 모든 Space와 전체 화면 앱 위에 표시하고, 드래그한 위치를 기억한다.
- 우클릭 메뉴에서 새로고침, 위치 초기화, 캐릭터 전환·관리, Claude Code 로그인, 로그인 시 실행, 종료를 제공한다.
- 사용 가능 상태는 `72%`, 로딩은 `...`, 미로그인은 `--%`, 호환되지 않는 응답은 `ERR`로 표시한다.

## Architecture

Swift 6.2와 AppKit으로 네이티브 액세서리 앱을 만든다. 순수 로직은 `TokenPetCore` 모듈로 분리하고, Keychain과 네트워크는 프로토콜 경계 뒤에 둔다. 투명한 비활성 `NSPanel`이 애니메이션과 고정 퍼센트 레이어를 표시한다.

사용량은 Claude Code가 저장한 OAuth 인증 정보를 읽어 Anthropic의 OAuth 사용량 경로에서 5분마다 갱신한다. `five_hour.utilization`을 `100 - utilization`로 변환하고 0...100으로 제한한다. 네트워크 오류에는 마지막 정상 값을 유지하며, 인증 토큰은 로그나 일반 파일에 기록하지 않는다.

## Constraints

- macOS 14 이상, arm64를 지원한다.
- 원본 `img/` 파일은 수정하지 않는다.
- 체크무늬 배경이 포함된 `2.png`, `3.png`는 빌드 자산 생성 단계에서 투명화한다.
- 사용량 엔드포인트는 공개 API가 아니므로 응답 변경을 안전한 오류 상태로 처리한다.
